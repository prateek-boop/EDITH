# EDITH Project Tech Stack Summary

An in-depth analysis of [`package.json`](file:///home/lucifer/Projects/EDITH/package.json) and related project configurations reveals that **EDITH** is a desktop-first Sovereign AI Workbench built with a hybrid **Electron + React 19 + TypeScript** frontend powered by a local Python loopback engine.

---

## 1. Project Identity & Architecture Overview

- **Package Name**: `edith-frontend`
- **Version**: `0.4.0`
- **Module Format**: ECMAScript Modules (`"type": "module"`)
- **Desktop Shell Entry**: [`electron/main.cjs`](file:///home/lucifer/Projects/EDITH/electron/main.cjs)
- **Architecture**:
  - **Desktop Container**: Electron 45 desktop shell with custom preload context bridge and local process supervisor.
  - **Frontend UI**: React 19 Single-Page Application (SPA) bundled with Vite 7.
  - **Embedded Engine**: Python loopback gateway (`server/gateway.py`) orchestrating local LLM inference, sandboxed execution, and cryptographic audit logs.

## 4. Key Highlights & Tech Stack Strengths

1. **Modern Leading-Edge Foundation**: Uses modern releases including **React 19**, **Vite 7**, **TypeScript 5.9**, and **Electron 45**.
2. **Rich Visualizations**: Incorporates both **Three.js / React Three Fiber** for immersive 3D graphics (e.g. Möbius core) and **D3.js** for 2D force-directed knowledge graph topologies.
3. **Developer-Centric Editing**: Equipped with **CodeMirror 6** and full **Remark/Rehype Markdown** processing for editing and viewing agent actions, proposals, and diffs.
4. **Comprehensive QA Infrastructure**: Pre-configured with **Playwright** and **Axe-Core** testing for automated functional and accessibility verification.
